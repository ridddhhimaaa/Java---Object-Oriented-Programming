# Object-Oriented Programming | Daily Java Practice

This repository is a daily learning and implementation journey focused on mastering Object-Oriented Programming (OOP) using Java. It contains daily coding practice, OOP concepts, Java implementations, exercises, mini-projects, notes, and steadily improving examples as I continue learning and building problem-solving skills.

The purpose of this repository is not to pretend mastery from day one. It is a genuine record of learning, understanding, practicing, and improving over time.

## Learning Objectives

This repository aims to help me:

- Understand the fundamentals of OOP
- Write clean and maintainable Java code
- Apply OOP concepts in real programs
- Strengthen Java programming skills
- Improve problem-solving ability
- Practice object-oriented design
- Build a strong foundation for software engineering interviews
- Progress from basic concepts to advanced OOP and design principles

## Topics Covered

### OOP Fundamentals

- Classes
- Objects
- Methods
- Constructors
- Instance variables
- Static members
- `this` keyword
- Access modifiers

### Four Pillars of OOP

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

### Inheritance

- Single inheritance
- Multilevel inheritance
- Hierarchical inheritance
- Method overriding
- `super` keyword

Java does not support multiple inheritance through classes. In practice, interfaces are the standard alternative when a class needs to inherit behavior from more than one contract.

### Polymorphism

- Compile-time polymorphism
- Method overloading
- Runtime polymorphism
- Method overriding
- Dynamic method dispatch

### Abstraction

- Abstract classes
- Abstract methods
- Interfaces
- Default methods
- Static interface methods

### Encapsulation

- Getters and setters
- Data hiding
- Access control
- Validation through methods

### Java OOP Features

- `final`
- `static`
- `this`
- `super`
- `instanceof`
- Object class
- `toString()`
- `equals()`
- `hashCode()`
- `clone()`

### Advanced Concepts

- Composition
- Aggregation
- Association
- Dependency
- Immutable classes
- Nested classes
- Inner classes
- Anonymous classes
- Functional interfaces
- Lambda expressions
- Generics
- Exception handling with OOP
- SOLID principles
- Basic design patterns

## Learning Roadmap

### Phase 1: OOP Fundamentals

Classes, objects, methods, constructors, access modifiers, `this`, and `static`.

### Phase 2: Four Pillars

Encapsulation, inheritance, polymorphism, and abstraction.

### Phase 3: Java OOP Deep Dive

Interfaces, abstract classes, Object class, overriding, overloading, `final`, `super`, and more.

### Phase 4: Object Relationships

Association, aggregation, composition, and dependency.

### Phase 5: Advanced OOP

Generics, nested classes, immutable objects, functional interfaces, and lambda expressions.

### Phase 6: Design Principles

SOLID principles, clean code, separation of concerns, and basic design patterns.

### Phase 7: Projects

Build progressively larger Java applications using object-oriented principles.
